Security Advisory KSA-2026-007: Authentication Bypass in Kestrel Verify On-Prem Agent

2026-09-25

Advisory ID: KSA-2026-007. Severity: Critical (CVSS 9.1). Published: September 25, 2026.

A flaw in how the Kestrel Verify on-premises agent validates signed SAML assertions allows a remote attacker to authenticate as any user in a connected directory. Versions 5.2.0 through 5.4.3 are affected. Cloud-hosted Kestrel Verify is not affected.

Fixed in version 5.4.4. Kestrel is not aware of exploitation in the wild. Customers should upgrade immediately; no workaround is available.
